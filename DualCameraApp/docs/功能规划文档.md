# 双摄录像APP 功能规划文档

> 版本：1.0
> 更新日期：2026-05-19

## 一、产品定位

| 项目 | 描述 |
|------|------|
| **产品名称** | 双摄大师（暂定） |
| **目标用户** | Vlog博主、内容创作者为主，兼顾普通用户 |
| **核心价值** | 一键双摄录制，多种画面模式，满足创意拍摄需求 |
| **离线特性** | 纯本地运行，无服务器依赖，数据不上传 |
| **平台** | HarmonyOS NEXT（API 18+） |
| **变现模式** | 付费下载 |

---

## 二、核心功能清单

### 2.1 录制模式

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **分屏录制** | 上下/左右分屏，两路画面并排显示 | P0 |
| **画中画录制** | 主画面+小窗口叠加显示 | P0 |
| **模式切换** | 录制中可切换分屏/画中画模式 | P0 |
| **独立文件录制** | 前后摄分别保存为两个视频文件 | P1 |
| **合并文件录制** | 双摄画面合成为一个视频文件 | P0 |

### 2.2 画面控制

| 功能 | 描述 | 优先级 |
|------|------|--------|
| **摄像头切换** | 双击或专用按钮切换对应画面摄像头 | P0 |
| **分屏比例调整** | 50:50 / 70:30 / 30:70 等预设 | P0 |
| **画中画位置** | 可拖动到四角任意位置 | P0 |
| **画中画缩放** | 双指缩放调整小窗口大小 | P0 |
| **画中画样式** | 矩形带圆角 | P0 |

### 2.3 参数调节（7项基础功能）

| 参数 | 前摄 | 后摄 | 调节方式 |
|------|------|------|----------|
| **变焦** | ✅ | ✅ | 点击画面调节或长按弹出变焦滑块 |
| **闪光灯/补光** | 补光（设置开启） | 闪光灯 | 点击画面调节 |
| **曝光** | ✅ | ✅ | 点击画面调节 |
| **曝光补偿** | ✅ | ✅ | 点击画面调节 |
| **对焦** | ✅ | ✅ | 点击画面位置对焦 |
| **防抖** | ✅ | ✅ | 设置中开关 |
| **色彩空间** | HDR | HDR | 设置中选择SDR/HDR |

### 2.4 设置项

#### 录像设置

| 设置项 | 选项 | 默认值 |
|--------|------|--------|
| 录制时长限制 | 5分钟 / 10分钟 / 15分钟 / 30分钟 / 无限 | 10分钟 |
| 文件保存方式 | 合并文件 / 独立文件 | 合并文件 |
| 默认录制模式 | 分屏 / 画中画（保持上次） | 保持上次 |

#### 画面设置

| 设置项 | 选项 | 默认值 |
|--------|------|--------|
| 分屏默认比例 | 50:50 / 70:30 / 30:70 | 50:50 |
| 画中画默认位置 | 右上 / 右下 / 左上 / 左下 | 右上 |
| 前置镜像翻转 | 开 / 关 | 关 |
| 网格线辅助 | 开 / 关 | 关 |
| 时间戳水印 | 开 / 关 | 关 |

#### 音频设置

| 设置项 | 选项 | 默认值 |
|--------|------|--------|
| 音频模式 | 共用音轨 / 独立音轨 | 共用音轨 |
| 麦克风选择 | 系统默认 / 外接设备 | 系统默认 |

#### 高级设置

| 设置项 | 选项 | 默认值 |
|--------|------|--------|
| 色彩空间 | 自动 / SDR / HDR | 自动（推荐最高） |
| 前摄补光 | 开 / 关 | 关 |
| 低光提示 | 开 / 关 | 开 |
| 存储空间提醒 | 开 / 关 | 开 |

## 三、用户流程

```
启动APP
    │
    ├── 检查权限（相机、麦克风、存储）
    │   └── 未授权 → 显示说明弹窗 → 引导去设置
    │
    ├── 初始化双摄设备
    │   └── 不支持双摄 → 提示并退出/单摄模式
    │
    └── 加载用户设置（上次状态）
            │
            ▼
      预览界面
            │
            ├── 点击画面 → 调节该摄像头参数
            ├── 长按画面 → 弹出变焦滑块
            ├── 双击画面 → 切换该位置摄像头
            ├── 切换按钮 → 切换该位置摄像头
            │
            ▼
      点击录制按钮
            │
            ▼
        录制中
            │
            ├── 显示录制时长计时器
            ├── 可切换分屏/画中画模式
            ├── 可切换摄像头
            ├── 可调节参数
            └── 达到时长限制 → 自动停止
                    │
                    ▼
              录制结束
                    │
                    ├── 保存视频到相册
                    ├── 显示预览缩略图
                    └── 弹出操作选项
                        ├── 查看视频 → 跳转华为相册
                        ├── 继续录制 → 返回预览界面
                        └── 删除视频 → 确认后删除
```

## 五、技术约束

### 5.1 API 限制

| 限制项 | 说明 |
|--------|------|
| **API版本** | 需要 API 18+（双摄并发）|
| **双摄拍照** | 当前不支持，仅支持录像 |
| **并发能力** | 必须先检查 `getCameraConcurrentInfos` |
| **功能限制** | 仅7项基础功能可用 |
| **并发模式** | 仅 `CAMERA_LIMITED_CAPABILITY` 模式 |

### 5.2 性能建议

| 建议 | 说明 |
|------|------|
| 双摄分辨率一致 | 降低编码压力 |
| 关闭不必要功能 | 防抖、HDR 按需开启 |
| 监控存储空间 | 避免录制中断 |

## 六、开发优先级

### P0 - MVP 核心功能

1. 双摄预览（分屏/画中画）
2. 双摄同时录制
3. 录制开始/停止
4. 视频保存到相册
5. 基础参数调节（变焦、曝光、对焦）
6. 摄像头切换

### P1 - 完整功能

1. 模式切换（录制中）
2. 独立文件保存模式
3. 完整参数调节（7项）
4. 设置页面
5. 相册跳转

### P2 - 增强功能（后续迭代）

1. 独立音轨模式
2. 外接麦克风支持
3. 时间戳水印
4. 网格线辅助
5. 低光/存储提醒

---

## 七、风险点

| 风险 | 应对策略 |
|------|----------|
| 设备不支持双摄 | 启动时检测，提示用户或降级单摄模式 |
| 双摄性能压力大 | 默认中等分辨率，高级分辨率需用户确认 |
| 存储空间不足 | 录制前检查，录制中监控，不足时提醒 |
| 权限被拒绝 | 引导去设置，说明弹窗解释必要性 |
| HDR 耗电发热 | 设置中提供关闭选项 |

---

## 八、默认配置

| 配置项 | 默认值 |
|--------|--------|
| 录制模式 | 保持上次使用状态 |
| 分屏比例 | 50:50 |
| 画中画位置 | 右上角 |
| 分辨率/帧率 | 系统推荐最高参数 |
| 用户自定义参数 | 保持用户设置 |
